# Institutional Governance Systems

This skill originated in Western Basin Worldbuilding Phase 10A/10B
institutional governance work. The repository is the canonical source for the
executable skill; the Hermes AppData directory is an installed operational
copy. The preserved original release was v0.1.0; the current architecture is
v0.2.0.

## v0.2.0 architecture

Generic core:

- [`SKILL.md`](SKILL.md)
- [`references/governance-core-qa.md`](references/governance-core-qa.md)

Western Basin project profile:

- [`references/western-basin-phase10-profile.md`](references/western-basin-phase10-profile.md)

Compatibility pointer for the v0.1.0 filename:

- [`references/phase10-governance-qa.md`](references/phase10-governance-qa.md)

The generic core is reusable for water utilities, public health,
environmental governance, energy, infrastructure, cyber-resilience, freight,
and similar institutional systems. The Western Basin profile adds project-
specific workflow, reproducibility, validation, and evidence examples.

Future edits should be made in this repository version first, validated,
committed, and then synchronized to the Hermes installed copy.
