# Erie Drift artwork

New summer Lake Erie game backdrop, generated on 5 October 2026 with the built-in
imagegen tool. The [manifest](manifest.json) retains the full prompt, hashes and
visual review. No reference image was supplied; no existing artwork was edited.

[Web image](lake-morning.webp) uses Sharp WebP quality 88, effort 6, retaining the
original dimensions. [PNG master](source_png.zip) preserves `lake-morning.png`.
The map, boat, fish, rod, sonar and drift animation are original Canvas drawings
in [the renderer](../../src/erie-drift/render.ts). No third-party sprite or audio
assets are used. Optional short game sounds are synthesized in the browser.

The shore, harbor and intake silhouette are a fictional composite. The panorama
shows a warm, sunlit summer morning with low shore, wind ripples, shade canopies
and working infrastructure. It is reused across the game's authored weather
presets; neither actual weather nor future ecological performance is established.
