# Phase 17A Visual Grammar v0.3

Accepted-for-use reference assets for the Phase 17 Atlas visual language.

**Status:** Phase 17A Visual Grammar v0.3 is **ACCEPTED FOR USE** as a viable
visual-language prototype. It is **NOT** a frozen final style specification.
Colors, fonts, precise line weights, page/grid dimensions, iconography, final
map projection conventions, animation timing, and final 3D rendering style
remain intentionally unfrozen.

## Files

- `phase17A_visual_style_test_sheet_v0_3.svg` — editable/master reference.
- `phase17A_visual_style_test_sheet_v0_3.png` — full-size proof render.
- `phase17A_visual_style_test_sheet_v0_3_grayscale.png` — grayscale QA proof.
- `phase17A_visual_style_test_sheet_v0_3_50pct.png` — 50%-size QA proof.
- `phase17A_visual_style_test_sheet_v0_3_grayscale_50pct.png` — grayscale
  50%-size QA proof.

These are accepted working references, not authoritative geography or frozen
final design. See the Phase 17A planning brief
(`docs/phase_briefs/phase17a_atlas_architecture.md`, section 19) for the
accepted-for-use concept list and the intentionally unfrozen items.
