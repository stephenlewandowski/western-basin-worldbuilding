# Public Atlas language guide

**Working public editorial reference · adopted 29 September 2026.** This guide does not change project status, canon or identifiers. See the [audit](../reports/public_atlas_language_ia_audit.md) for findings and scope.

## Name the reader's subject

| Role | Preferred wording |
| --- | --- |
| Illustrated place/page | Futurescape |
| Collection | 2075 Futurescapes; Futurescapes in navigation |
| Main picture | Lead image |
| Closer work/maintenance picture | Working detail |
| Explanation section | How it works |
| Diagram type | System inset |
| Future-scene status | Scenario and design concept |
| Research/concept essay collection | Studies, with each study's actual evidence/scenario label |
| Source and uncertainty explanation | Methods |
| Reader-visible additions/corrections | Updates |

Use **Glass City 2075**, **Lake Erie Energy & Security Coast 2075**, **Maumee Bio-Ag Landscape 2075**, and **Industrial Metabolism 2075** in public titles and links. Keep HF IDs, phase IDs and GBI numbers in internal paths and records.

## Write the limits where they help

- Caption: “Composite [place]-derived 2075 scenario and design concept.” Retain each scene's accepted place qualifier.
- Page: explain **what is grounded** and **what is speculative**, plus the specific claims the scene cannot support.
- Methods: define E/S/C/K, source provenance, model limits, qualitative geometry and reproducibility. Visual “design concept” describes the relevant K material; it does not promote it to fictional canon.
- Repository: keep review gates, production decisions, hashes, phase history and detailed status.

“Published” is useful in a dated announcement. Avoid “accepted,” “hero set,” ordinal release badges and production codes in everyday page copy. Keep physical drainage gates, material acceptance and scientific review where they describe the subject. Do not use global search-and-replace.

Prefer one concrete sentence about what people do to a paragraph about how an image was produced. Keep generated-image provenance available in Methods. Preserve source links, stable routes, filenames and historical records.
