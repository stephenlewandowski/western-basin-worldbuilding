# Phase 12C — Vector Ecology Futures, 2050 / 2075

Status: APPROVED SCOPE / NOT IMPLEMENTED.

## Approved scope

Phase 12C may later create separate qualitative vector-ecology futures for
2050 and 2075 over the factual Phase 12A baseline and the qualitative Phase 12B
dependency layer. It may represent alternative changes in seasonal suitability,
habitat/connectivity, hydrology and standing-water conditions, urban/container
habitat, host ecology, surveillance capacity, and vector/environment/human-
system interfaces through explicit assumptions and separate future-state
records.

Future records must carry scenario identifier, horizon, baseline object where
applicable, change type, reality status, canon status, relationship basis,
assumption/source basis, plausibility, and uncertainty. Projection evidence,
if later authorized, must retain model/ensemble, reference period, method,
spatial/temporal resolution, and limitations. A future scenario is not a
forecast unless an evidence-backed method is separately approved.

## Required boundaries

Do not infer unsupported future range expansion, establishment, abundance,
pathogen prevalence, human contact, infection, disease incidence,
hospitalization, mortality, or local transmission. Do not create individual
risk or exposure/dose models, neighborhood disease-risk surfaces,
vulnerability/EJ scores, or precise future vector distributions. Keep vector
presence, abundance, pathogen detection, contact, infection, and clinical
disease as separate states. Preserve sampling-effort and surveillance
limitations; do not infer absence from non-detection.

No full infectious-disease dynamics, biosecurity, or Phase 13 content is in
scope. Phase 12C must not modify Phase 12A/12B factual or qualitative working
artifacts, accepted/frozen Phase 1–11 artifacts, or the project canon.

## Expected products when separately authorized

Separate qualitative scenario assumption/evidence/state/comparison tables,
scenario reports, Maps 40/40b if numbering remains sequential, deterministic
Python and independent R validators, a phase manifest, a bounded independent
review, and explicit comparison of baseline versus future layers.
