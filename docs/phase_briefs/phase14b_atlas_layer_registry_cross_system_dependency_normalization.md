# Phase 14B — Atlas Layer Registry & Cross-System Dependency Normalization

Status: APPROVED SCOPE / NOT IMPLEMENTED.

Phase 14B is intentionally deferred. Its future scope may define an Atlas layer registry and normalize cross-system dependency joins after Phase 14A has established the ontology, identity, evidence, provenance, and relationship inventory.

Deferred questions include:

- how Atlas layers reference CSV, GeoPackage, GeoJSON, YAML/JSON, scenario, and network artifacts;
- how cross-system relationship classes are selected without collapsing unlike native semantics;
- how scenario mechanisms are crosswalked across unlike A/B/C labels;
- how repeated population dependency rows, energy terminology, and conceptual endpoints participate in a future join contract;
- how native spatial scale, temporal basis, evidence status, uncertainty, and non-claims remain visible in integrated views.

Phase 14B must not rewrite local identifiers or accepted/frozen phase artifacts. It must not be started by the Phase 14A package.
