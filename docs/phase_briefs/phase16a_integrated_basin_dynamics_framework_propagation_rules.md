# Phase 16A — Integrated Basin Dynamics Framework & Propagation Rules

Status: IMPLEMENTED / VALIDATED / INTEGRATED / AWAITING SOL ACCEPTANCE.

## Purpose

Create a bounded qualitative framework that traces:

STRESSOR → INITIAL SYSTEM EFFECT → DEPENDENCY / INTERFACE → CROSS-SYSTEM PROPAGATION → RESPONSE / ADAPTATION → RESIDUAL OR SECOND-ORDER EFFECT

## Inputs

Consume, without rewriting, frozen Phase 14 system identities, Atlas mappings, normalized relationship classes, dependency crosswalks, evidence vocabulary, endpoint roles, joinability metadata, and Phase 15A/15B technology interfaces and convergence regimes.

## Products

- bounded vocabulary for stressors, qualitative system states, propagation mechanisms, responses, feedback/coupling, and technology modifiers;
- propagation relationship and rule tables with lineage, evidence class, enabling/limiting conditions, temporal/spatial character, uncertainty, reversibility, and scenario status;
- reusable multi-stage chain template for Phase 16B;
- qualitative system × stressor pathway matrix;
- approximately four to six candidate Phase 16B compound stress tests, identified only;
- one Atlas-facing conceptual stress-propagation figure;
- reproducible Python builder, Python validator, independent R validator, working artifact manifest/check, QA reports, and one bounded independent review.

## Boundaries

No numeric risk/resilience/vulnerability scores, probabilities, forecasts, calibrated dynamics, unsupported causal claims, guaranteed failure, health-outcome forecasting, harmful biosecurity detail, operational cyber/attack detail, or frozen-artifact changes. Co-location is never propagation evidence. Cycles are not runaway feedback without explicit support.
