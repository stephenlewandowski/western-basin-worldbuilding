# Data and Asset Licensing

The repository's MIT license covers original code and original documentation. It does not override the terms of third-party datasets or imagery.

Phase 1 uses and attributes public source material from USGS, USFWS, US EPA, NOAA, GLOS/IOOS, the City of Toledo, and Ohio EPA. Consult [metadata/sources.yml](../../metadata/sources.yml) and [reports/water_system_sources.md](../../reports/water_system_sources.md) before redistribution or derived use.

Analytical outputs combine source geometry, documented interpretation, and original cartographic work. Source attribution must be retained.

Concept-art and generated-map assets are stored for project development and provenance review. Their inclusion does not declare them public-domain geographic data or authorize using embedded labels/geometry as factual sources.

The Great Black Swamp reference image is non-georeferenced and reference-only. Its original source/license requires follow-up before external publication beyond repository review.
